# PTGU Notification Telegram Bot

## How to use

### Import

```go
import (
  PTGUnotification "github.com/parinyapt/golang_utils/notification/telegram/v1"
)
```

### Example

#### Send message V1

```go
func main() {
  telegramBot := PTGUnotification.New("TELEGRAM_BOT_TOKEN")
  err := telegramBot.SendMessage(PTGUnotification.TelegramSendMessageOption{
    ChatId: "CHAT_ID",
    Text:   "MESSAGE",
  })
  if err != nil {
    panic(err)
  }
}
```

## How to generate a Telegram Bot Token and Chat ID

1. Add the BotFather bot on Telegram (@BotFather).
2. Create a new bot by sending the `/newbot` command.
3. Follow the instructions to create a new bot.
4. Copy the token generated by the BotFather.
5. Add the bot to a group or start a chat with the bot.
6. Get the chat ID by requesting the `getUpdates` API endpoint.

Reference:

- [Telegram Bot API](https://telegram-bot-sdk.readme.io/reference)
- [Telegram Bot API - getUpdates](https://telegram-bot-sdk.readme.io/reference/getupdates)
